# 1.11.18 朗读悬浮条避让

日期：2026-10-23。版本号 1.11.18 / 55。

## 最终行为

- 播放条保持悬浮，正文视口不因开始、暂停或停止朗读而改变。
- 点击正文呼出阅读顶栏和底栏时，播放条随着底栏展开平滑上移；收起工具栏时回落到屏幕底部。
- 上移距离由底栏实际高度决定，不写死像素；导航栏留白只在悬浮条贴底时加入，避免重复空隙。
- 打开目录、排版设置、全文搜索或听书面板时暂时隐藏阅读悬浮条，关闭后恢复。听书面板继续提供暂停状态和停止朗读入口。
- 其他页面保持原有全局悬浮播放条。

## 实现

阅读页在同一个底部浮层内组合播放条与阅读工具栏；只让工具栏展开/收起，不改变正文布局约束。根页面恢复叠放布局，在阅读页不重复绘制全局播放条。播放条使用当前阅读主题。

## 验证

最终 APK 构建、静态检查通过。静态检查 0 错误，47 条既有警告、11 条提示。

已覆盖安装到 vivo V2339FA（1260×2800）。用独立测试书启动真实朗读并暂停，核对五个底栏按钮的完整点击区域与播放前一致（纵向 2525–2702 像素），悬浮播放按钮在工具栏显示时为 2083–2251 像素；工具栏收起后回落到 2506–2674 像素，再显示工具栏时恢复原位。

实际点击底栏中央的朗读入口成功；听书面板内没有额外悬浮控制条覆盖，滚动后可完整看到停止朗读按钮。排版设置面板同样隐藏悬浮条，关闭后恢复。

全文搜索面板打开/关闭与悬浮条恢复通过；实际点击听书面板的“停止朗读”成功，停止后底栏仍保持原位置。完成后仅删除本次测试书和测试缓存，书架恢复原有 13 本，电脑配对与自动模型保留。
