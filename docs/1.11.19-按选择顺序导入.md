# 1.11.19 按选择顺序导入

日期：2026-10-24，版本 1.11.19 / 56。

导入多个文件和向已有书籍追加文件，均新增“文件顺序”：默认“智能排序”，可改为“按选择顺序”。文件顺序独立于分章方式；无编号、无标题的散篇，可选择“合并成一本书”＋“按选择顺序”＋“每个文件作为一章”。

选择顺序模式保留文件列表顺序，跳过文件名排序和导入完成后的章号重排；追加时按列表顺序放在原书末尾。每个文件内部仍按用户所选分章方式解析。取消对话框不写入书籍。

系统文件选择器可能按自身规则返回多选结果，应用无法凭空恢复它未提供的点击历史。因此界面展示实际文件顺序、编号及上下调整按钮，最终导入以下方列表为准。模拟器本次系统多选保留了 zeta、alpha、middle 的点击顺序，但不保证所有文件管理器都如此。

预览与实际导入使用同一份列表和排序选项。切换选择或调整顺序后重新预览，不继续显示旧顺序的采样结果。中、英、日文同步更新说明，避免旧文案仍声称始终自动排序。
