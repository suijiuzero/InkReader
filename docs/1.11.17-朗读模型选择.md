# 1.11.17 电脑语音与朗读模型选择

日期：2026-10-23。先在 Pixel_6 模拟器（Android 17 / API 37，1080×2400）验收；随后按用户要求，覆盖安装到 vivo V2339FA 真机（1260×2800），核对版本为 1.11.17 / 54，保留已有书架及电脑配对。

## 界面

听书面板标题改为“电脑语音”，连接及状态文案同步使用该名称。“试听晓晓”改为“试听语音”，原独立日语试听入口并入所选模型的统一试听。

按钮为等宽两列：第一行“测试连接 / 试听语音”，第二行“取消配对 / 选择朗读模型”。下方显示当前模型。已用实际 UI 元素边界核对两行与两列对齐。

模型选择使用独立圆角对话框，提供耳机图标、三张选择卡片、单选状态和“自动”推荐标记。卡片下方说明适合的语言；“使用提示”随草稿选项变化。下方明确说明保存、试听立即生效，以及听书需要停止后重新开始。内容在高度受限时可滚动，保存按钮留在固定底部。浅色、深色均使用阅读主题配色；深色保存按钮使用深色文字，提示使用更清晰的次级文字颜色。

点“保存选择”才写入；取消或关闭只丢弃草稿。选择在应用重启及取消配对后保留。

## 行为

| 选择 | 实际声音 | 说明 |
|---|---|---|
| 自动 | 按章节/句子语言切换 | 中文和英文用晓晓，日语优先本地七海 |
| 晓晓 | 固定本地晓晓 | 适合中英；即使有假名也不自动改用七海，日语可能被跳读 |
| 七海 | 固定本地 Nanami | 适合日语，包括纯汉字日文；不保证中英读音自然 |

统一试听使用当前选择。自动模式参考当前阅读章节语言；晓晓播放中文样本，七海播放日语样本。保存时若正在听书，不打断正在播放的音频；本次服务会话和下一句预取使用启动时的同一模型，停止重启后采用新选择。状态区同时显示本次正在使用的模型，避免把待生效的选择冒充为当前声音。

模型仅用于电脑语音，离线仍按既有规则回退手机 TTS。未安装指定模型或电脑服务版本旧时给出说明，不悄悄把手动选择改成自动。

电脑健康接口报告实际可用 `models`；合成请求增加 `model: auto/xiaoxiao/nanami`。旧客户端省略字段时保持自动行为。电脑服务已更新，身份与配对码保留。

## 验证

- 140 项 JVM 测试、8 项 Python 桥接回归通过；主 APK 和 AndroidTest APK 构建成功。静态检查 0 错误，47 条既有警告、11 条提示。
- 真实本地 SAPI 合成六种组合：自动中/日、固定晓晓读日文、固定七海读中文/日文、固定晓晓读英文。逐个核对实际音色及有效 WAV；手动选项确实覆盖自动语言规则。固定晓晓读日文的样本仅约 0.69 秒，说明部分假名会被跳过，因此界面明确提示其语言限制，不将其宣传为日语音色。
- 模拟器真实点击核对改名、两列布局、三张卡片和提示；草稿取消不改变选择；三个选项保存后的试听均播放完成；应用重启后仍记住七海，再恢复自动。
- 在合成日文书正文中启动七海，状态区显示七海；朗读期间把偏好改为自动，当前会话仍保持七海；停止再启动后显示自动。测试完成后停止朗读。

功能点击工具：`tools/testing/exercise_voice_models.py`。模拟器原始结果保存在本机忽略目录 `app/build/audit/voice-models-2026-10-23/`，含 `sapi-model-results.json`、`model-ui-results.json`、`reading-model-results.json` 和浅深色截图。模拟器使用专用 ADB 转发访问电脑。

## 真机补充验收

手机通过实际的同一局域网 Wi-Fi 访问电脑语音服务，没有使用 ADB 网络转发。原有配对身份及密钥一致，连接检测显示“已连接电脑 · 晓晓和日语音色可用”。本次验证的是已有配对的局域网连接，不据此宣称重新发现电脑或首次配对已通过。

通过系统文件选择器实际导入独立合成文本 `INK_VOICE_PHONE_20261023.txt`，预览识别日语、中文、英文三章。导入后书名按首章显示为“第一章 日语朗读”。系统选择器搜索曾提示暂时无法加载内容，改从本机存储的 Download 文件夹按修改日期排序后成功选择。没有打开原有书籍测试。

真机核对按钮改名及两行等宽布局、取消草稿不保存；七海、晓晓、自动三个选项均保存成功，手机试听均显示“试听完成”。截图检查模型卡片、提示、底部保存按钮均完整可见。用户同时反馈“成功了”；声音主观听感以用户反馈为准，自动验收记录的是合成及手机播放完成状态。

保存七海后强制停止并重启应用，重新进入面板仍显示“当前模型：七海”，随后恢复“自动”。从日语章头实际启动听书，手机出现正在朗读状态；暂停后打开会话设置，核对“电脑语音 · 自动”和日语章标题。最后停止测试播放。

另发现既有悬浮播放条会遮挡阅读底栏中部和听书面板底部的一部分点击区域；本次通过底栏标签下缘打开面板，仍可停止播放。该布局问题尚未修复，不把本次验收写成无已知问题。

真机截图与逐项结果位于本机忽略目录 `app/build/audit/phone-voice-2026-10-23/`。

收尾时删除仅本次导入的三章测试书和对应下载文件，核对书架恢复原有 13 本；最终设置为 `auto`、电脑语音开启、原 LAN 地址与配对保留，测试播放已停止。

新文件包括 `ComputerVoiceModel.kt` 与 `VoiceModelDialog.kt`。模型选择仍是已有本地音色的路由，不下载或上传用户书籍，不改动书架数据。
