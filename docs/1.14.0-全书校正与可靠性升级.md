# 1.14.0 全书校正与可靠性升级

状态：本报告保留 1.14.0 候选阶段的验证。后续复审新增五个反例并复现问题，修复与最新交付见 [1.14.1 复审记录](1.14.1-复审修复与验证.md)。原有有限测试通过不能代表未覆盖场景没有问题。

日期：2026-10-26；版本 1.14.0 / versionCode 64。目标 API 34、最低 API 24。Pixel_6 模拟器实际 API 37，专用序列号 emulator-5554；未操作其他项目模拟器和手机。

## 变更

- 单 TXT 和已有书重分章共用全书校对，分页 40 行，支持标题搜索、原文行跳转、手工增删边界，显式调整最多一万处并绑定完整源指纹。
- 重复编号候选只在可靠前后锚点之间保守比较。卷、书末特殊章与分段号受保护；证据不足保留疑点，不等同于对任何书均可靠的全局最优判定。
- TXT 多文件预览、合并、追加、自定义规则使用磁盘索引，大书重分章仅保存需要的批注和样式端点，正文分阶段落盘。
- 导入作业与每源完成凭据持久化；完成凭据和章节同事务，支持暂停、恢复和结束任务。
- 完整逻辑备份与添加副本恢复；分章操作提供每书最近一次持久撤销。
- 搜索按块读取并逐字校验，磁盘过滤器只跳过确定不匹配的章节；全书页数按正文、样式和排版签名缓存。
- 真实来源摘录和冻结标注；GitHub 构建／回归／静态检查配置。

## 已发现并修复的问题

- 失败的结构编辑原本会提前覆盖旧撤销点；改为完整快照暂存，事务成功后原子替换，故障注入验证旧点可用。
- 关闭纠错记忆重分章时会把旧记忆清空；改为仅明确调整才保存，临时关闭与清除分开。
- 完整恢复现在严格验证阅读设置类型和数值，避免损坏设置在后续启动时造成类型错误。
- 补充平面大小写字母可能被 UTF-16 三元组过滤器错误排除；检测到这类码点就回退实际匹配，新增冷热缓存回归。
- 原文行跳转前方长段落把目标挤出首屏；指定行现在直接显示在列表开头，查询／分页重置滚动，勾选保留当前位置。
- TextStyle 运行期对象哈希使页数缓存跨进程失效；改用字号、行距、字距、字体、段距、缩进、尺寸、密度、语言／方向和源文件身份。实际杀进程重开后 72 页结果复用，无新增缓存文件。

## 性能与剩余问题

20 章约百万字符子串查询两轮分别为 272→18 ms、285→17 ms；暖查询跳过 19 个确定不匹配章节，命中位置与上下文不变。修改最后一章后旧结果消失、新内容可搜到。此为该样本和模拟器结果，不能推广成所有书源的固定倍数。

SwiftShader 软件渲染下，40 次快速前后点击共约 5.86 秒，119 帧中 59 帧被系统标记卡顿（49.58%，P50 40 ms、P95 65 ms）。这是仍然存在的界面流畅度限制，本轮没有匹配的旧版对照，不能据此声称已改善或将其全部归因于驱动；硬件渲染真机需另测。本轮未测试实体手机。

## 来源样本与首次失败

新增 3 份真实来源摘录，共 24 个标题和 96 个完整正文段落；分别为英文 Alice、德文 Kafka、中文阿 Q。前两份用于开发，阿 Q 首次留出时标题与边界通过，正文核对器因原文含 9 个零宽字符而失败；按既有导入规范修复核对器后，冻结输入与答案未改。该样本现已用于回归，不能再称作未见留出。具体出处、原始 HTML 指纹、提取范围见 `tests/fixtures/real-source/`。这些标注由开发者依据源标题提取，独立于分章输出，未经过第三方盲标。

## 边界

导入单源限制 200 MiB；整书重建原文限制 2 亿 UTF-16 字符，另受 50 万索引行、临时空间与 100 万坐标端点预算限制。非 TXT 解析和超大单章阅读仍可能受内存影响。恢复添加副本，重复恢复会重复；电脑配对、目录授权及活动任务不恢复。撤销会替换该书到最近一次分章前的完整状态，每书一份。缓存可丢弃，不能代替数据备份。

模拟器结果不能证明所有实体手机、Android 版本或所有来源都可靠。GitHub 工作流已写入，尚未推送触发远端运行；Android 测试 APK 构建不代表远端设备测试已运行。
