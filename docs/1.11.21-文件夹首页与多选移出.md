# 1.11.21 文件夹首页与多选移出

日期：2026-10-24，版本 1.11.21 / 58。

只调整“导入 / 追加文件”里的文件选择页，不更改墨阅的书架首页。

“*”代表文件选择器内部的文件夹首页，展示已经添加的授权目录卡片。可以继续添加多个文件夹，在各个文件夹间来回选择；点击“*”或在目录根部返回上级，回到此页，已选文件及次序保留。首次升级迁移旧版记住的单一文件夹入口。

长按卡片进入文件夹多选，可全选、取消和批量移出首页。移出仅删除入口，不删除手机文件，不撤销其他导入流程可能仍在使用的读授权。如果其中有已选文件，确认框提供“同时取消这些文件夹内的已选文件”选项；默认不勾选，保留文件队列。勾选后只取消相关目录的文件，其余文件维持相对次序并连续编号。晚返回的目录名称查询不会重新加回已移出的入口。

确认导入会逐一检查队列中文件所属目录的读授权，不再要求所有文件来自最后进入的同一个文件夹。因此从首页移出入口后，保留在队列里的文件仍可以继续导入。
