# 1.11.11 · 局域网电脑晓晓验证

日期：2026-10-21；Android versionCode 48。

## 实现与部署

- Windows 已有 NaturalVoiceSAPIAdapter，本地精确音色 token 后缀为 `Local-Xiaoxiao`。生成固定测试句成功，正常语速与变速分别获得 228708 / 163242 字节 WAV。没有运行压缩包中的注册表脚本，没有改动音色安装。
- 新增 `tools/natural-voice/`：标准库 Python HTTP/UDP 桥接、持续运行的 PowerShell SAPI 工作进程、配对页面和登录自启/移除脚本。已添加当前用户登录自启快捷方式；尚未通过实际注销/重启验证该快捷方式。
- 墨阅阅读页 → 听书面板新增配对开关、「测试连接」「试听晓晓」。没有新增全局设置入口。手机已完成首次配对并启用自动连接。
- 电脑服务仅使用本地 Xiaoxiao，手机播放 WAV。当前句播放时预取下一句；暂停/跳句/切章隔离旧回调，失败时从当前句回退手机 TTS，后台约每 30 秒尝试恢复电脑连接。
- 配对凭据不参与备份。仅连接私有数字 IPv4，不跟随 HTTP 重定向；电脑要求鉴权并限制输入及返回大小。局域网是 HTTP 明文，适用于可信家庭网络。
- 本机同一 Wi-Fi 已直接互通，未改动防火墙。没有公网映射或云端语音转发。

## 限制

- 尚未经过长时间后台、锁屏、Wi-Fi 切换、电脑重启或其他机型验证；自动重试的 30 秒时间点未单独做长时间计时验证。
- 「测试连接」检查配对电脑可达性；音色实际可播放由「试听晓晓」确认。是否实际听到声音仍取决于手机音量、输出设备和用户听音确认。
- 电脑断线时若手机 TTS 本身不可用，则暂停并显示手机引擎提示。
- 电脑语音服务需要电脑登录、唤醒并与手机互通；访客网络设备隔离可能使自动发现和连接失败。

电脑使用方式见 [电脑晓晓说明](../tools/natural-voice/README.md)。
