# 墨阅 · 使用说明

版本 **1.14.1** ｜ 包名 `com.inkreader` ｜ Android 7.0（API 24）及以上
支持 TXT、DOCX、Markdown、PDF、HTML、EPUB。更新日期：2026-10-26。

新增多语言章标签、Unicode 十进数字、保守的纯数字标题和中途格式切换识别；合章按编号范围查漏。原始标题与正文保留，无法确定的缺章不会补造内容。

单 TXT 预览取消分章点时可记住本书调整，重分章可沿用、关闭或清除。匹配依据是标题和附近正文；改变或歧义时跳过，不影响其他书。全书校对支持最多一万处明确调整。TXT 预览、独立成书、合并、追加、自定义规则和大书重分章使用磁盘索引；单文件200 MiB、TXT索引50万行上限。大书还需临时存储并限制批注端点；超大单章阅读及其他格式解析仍可能受内存限制。

墨阅在本机保存书籍、进度、批注和封面，不需要账号，没有广告。电脑语音为可选功能，只在配对并启用后连接同一可信局域网中的电脑。

## 快速开始

1. 在书架点「导入」，添加小说所在的文件夹并授予读取权限。
2. 按希望的顺序点击文件，右侧序号就是预计导入次序；底部可展开核对或调整。
3. 点「继续导入」，选择各自成书或合并为一本书，再确认文件顺序与分章方式。
4. 点封面阅读；点正文中央呼出或收起工具栏。

没有文件名编号、文件里也没有章节标题的散篇，可选择「合并为一本书」＋「每个文件作为一章」＋「按选择顺序」。

## 安装与更新

- 安装可信来源的 APK。升级时使用相同签名的包覆盖安装，避免为了更新先卸载应用。
- 卸载或清除应用数据会移除本机书库。导出重要正文；TXT 导出不包含私人批注，不能代替完整书库备份。
- 系统备份／换机迁移可能包含数据库、正文、笔记、进度与封面，是否执行由 Android 系统控制；电脑语音配对凭据排除在备份之外。
- 当前构建包使用何种签名取决于构建任务与本机配置，详见贡献指南。debug 包用于自测，发布构建必须配置正式签名。

## 选文件：文件夹首页与预计导入次序

### 添加与切换文件夹

选文件页的「*」是文件夹首页，与墨阅书架首页不同。可添加多个小说文件夹，点击卡片进入；点「*」或在目录根部返回上级，可回到此首页。跨文件夹选择时，队列及其先后顺序保留。

授权由系统提供。Android 11 及以上通常限制下载目录等根目录的授权，可在 Downloads 中建立小说子文件夹并选择它。授权失效时重新选择；授权范围以系统实际授予为准。

长按首页卡片进入文件夹多选，可全选、取消及批量移出入口。移出不删除手机文件；默认保留这些目录里已经选中的文件，也可勾选同时取消选择。为保留已选文件的可读性，移出入口不会撤销所有旧读取授权。

目录内正常点击文件夹进入，长按文件夹不触发批量操作。右上角「系统选文件」可使用系统选择器；其返回顺序由提供方决定，仍应在导入确认中核对并调整。

### 单选、搜索与顺序预览

点击文件进行选择或取消，序号连续显示。取消后再次选择的文件会加入队尾。搜索只筛选当前目录，不清空既有选择。文件名浏览排序只影响后续选择，不会重排已选队列。

底部展开「预计导入次序」，可以上移、下移或移除文件；清空只清除本次选择，不删除源文件。大批文件的选择草稿保存在应用私有存储中，页面恢复只使用小令牌，避免大量长文件名触发 Android 状态大小限制。草稿不是永久书库备份。

### 长按批量选择

| 操作 | 范围与顺序 |
| --- | --- |
| 从此文件顺序选择 | 包含当前文件，到显示列表末尾 |
| 从此文件倒序选择 | 包含当前文件，倒序到显示列表开头 |
| 全部顺序选择 | 当前列表全部文件，按显示顺序 |
| 全部倒序选择 | 当前列表全部文件，按显示顺序的逆序 |
| 选择两个文件之间的范围 | 长按文件为起点，再选终点；包含两端，按起点到终点的方向加入 |

批量操作使用打开菜单时的当前目录、搜索条件和显示顺序，不递归选择子文件夹。已选文件保持原位，未选文件去重后追加。菜单显示范围内文件数，完成时提示实际新增数。取消菜单或返回选项不会改变选择。

## 导入、分章与文件顺序

### 两种导入方式

- 每个文件各自成为一本书：适合一次选择多本独立小说。
- 合并为一本书：适合同一本书分散在多个文件，支持自定义合并书名。

「文件顺序」与「章节划分」是两项独立设置：

| 文件顺序 | 行为 |
| --- | --- |
| 智能排序 | 按识别到的文件名或章节编号等规则安排顺序 |
| 按选择顺序 | 按确认列表依次导入，不再按文件名或章号重排；追加内容放在原书末尾 |

由墨阅内置选择页继续导入时默认保留选择顺序。使用系统选择器时，请核对其返回列表，并在需要时选择「按选择顺序」和手动调整。

### 章节划分

| 方式 | 适用情况 |
| --- | --- |
| 智能识别 | 自动使用文档标题结构或正文标题模式 |
| 按文件内标题 | 强制按提取出的文件内部标题尝试分章 |
| 每个文件作为一章 | 不拆文件正文，文件名作为章节名，适合无标题散篇 |
| 严格章标题 | 优先「第X章／回」「Chapter N」等明确章级标题 |
| 数字序号 | 也识别数字列表、中文序号、括号序号等标题形态 |
| 固定字数 | 不依赖标题，按约定字数及段落边界切分 |
| 自定义 | 按短行前缀或正则表达式匹配；无匹配或规则无效时可能按字数兜底 |

确认前查看预计章数与示例。多文件预览最多采样前几个文件，章数可能是估计，不代表所有文件都已完整解析。实际导入有失败时查看逐文件明细。

### 编码与识别详情

在导入确认页点击「查看识别与疑点」：

- TXT 自动优先使用 BOM / 合法 UTF-8，再比较 GB18030、Big5、Shift-JIS（Windows-31J）和 EUC-JP。自动判断不是保证，看到不确定提示或乱码时请核对文字预览。
- 单个 TXT 可选择文字编码，切换后会重新预览，并清除之前的分章点调整，避免旧行号套到新解码文本上。
- 显示编号补查、本卷格式、疑似缺章、目录核对和按字数拆分等依据。找不到的章节只提示，不生成正文。
- 单个 TXT 内联显示前 40 项，可进入全书校对分页搜索和增删分章点；标题和正文合并到相邻内容，不删除文字。多文件时详情仅来自第一个文件，需调整请单独导入。
- 多文件预览最多检查前 5 个文件，其余数量为估算；读取失败数量会单独显示。

### 章节识别能做什么

- 优先使用 DOCX 标题样式、Markdown 标题、HTML 标题层级，以及 PDF 可提取的字号信息等文档结构。
- 支持章、回、节、话、卷、部等中日文形式，Chapter、Part、Book、Volume 等英文形式，识别常见阿拉伯、全角、中文／大写中文及罗马数字等编号。
- 支持最终章（上／中／下）、序章、终章、番外、Prologue、Epilogue、幕間等形式；特殊章节与卷边界有各自的处理规则。
- 编号连续性查漏将编号统一后，只在两个已识别标题之间的缺口放宽查找；分卷重置、同号上下篇和特殊章节不直接当成普通连续章。找不到原文标题就放弃，不生成缺失正文。
- 正文引用、特殊排版、极短章节仍可能有歧义。已有书不因升级自动改章序；需要时使用章节管理，并先核对结果。

## 格式、编码与限制

| 格式 | 能力与边界 |
| --- | --- |
| TXT | UTF-8、UTF-8 BOM、GBK／GB18030、UTF-16 等常见编码；没有 BOM 且没有明显特征的编码仍可能存在歧义 |
| DOCX | 提取正文与标题样式；旧 DOC 不支持；图片、复杂表格与原始页面版式不保证还原 |
| Markdown | `.md`、`.markdown`，支持标题、强调、列表、引用、代码、表格、链接等文字排版；图片使用文字占位，不加载远程图 |
| PDF | 提取文字版文本、推断标题和部分页边重复内容；不做 OCR；多栏、旋转、字体缺失及复杂版面可能影响阅读顺序 |
| HTML | `.html`、`.htm`、`.xhtml`，提取正文与标题，不运行脚本或作为网页浏览器加载 |
| EPUB | 按容器与 OPF spine 阅读顺序提取文字，不完整复刻原网页布局 |

MOBI、AZW3、旧 DOC 以及普通 ZIP 压缩包不作为上述格式直接支持。单个源文件超过 **200 MiB** 会拒绝导入；DOCX／EPUB 还设有解压预算。小于该大小不代表任意复杂文档都能在有限内存中解析。

导入和搜索在后台执行，大书仍需要时间。取消会在读取块、文件、章节等检查点停止后续工作；第三方解析器内部的单次计算不保证立即中断。已经完整提交的文件可能保留，中断后重试前先检查书架以免重复。

## 阅读、主题与全局排版

- 左右翻页：滑动或点左右边缘；动画可选平移、覆盖、仿真、无动画。
- 上下滚动：连续滚动正文；可以跨章继续阅读。
- 点中央显示或收起工具栏，目录可切换章节与笔记；拖动进度条预览章节，松手跳转。
- 可选音量键翻页；工具栏或操作面板出现时按界面状态处理音量键。
- 书架菜单 → 设置与阅读页设置共用全局排版：字号、行距、段间距、字距、边距、字体、缩进、亮度、主题、翻页方式与动画。
- 五套主题：月白、纸白、护眼、深墨、纯黑。改变排版会重新分页，后台全书页数尚未完成时可能显示占位或更新中的总页数。
- 朗读条保持悬浮，工具栏出现时自动上移；不通过整体推高正文来避让。

长按正文后可拖动扩选、高亮、书签和笔记；左右翻页模式下可下拉整页打标签。批注锚点按正文位置记录，编辑、合并、拆分与重分章会尝试同步迁移；大幅重写或无法可靠对齐时应检查提示与结果。

## 书架、章节与编辑

书架支持网格／列表、排序、书名与作者搜索、自定义封面、分组。一本书最多属于一个分组。

书籍详情和章节管理提供新增、编辑、重命名、移动、排序、删除、合并、拆分、重分章与追加文件。追加时也可选择智能排序或按选择顺序；后者总是放在现有章节末尾。

编辑器停止输入约 1.2 秒自动保存，正常返回时等待保存完成。强行结束应用进程可能丢失最后未保存的输入。删除或重分章前核对目标；重要正文先导出。

## 听书与电脑语音

### 手机语音

阅读页 →「朗读」打开听书面板，可选择从当前页或章首开始，调整语速、音调与定时停止；通知栏、锁屏和耳机控制依赖设备与权限支持。手机朗读需要安装系统 TTS 引擎及对应语言数据，墨阅不内置完整手机音色包。

### 同一局域网的电脑语音

1. 在 Windows 上准备本地语音适配器、晓晓音色及本项目电脑语音服务；日语还需七海。具体安装与端口说明见 [电脑语音文档](../tools/natural-voice/README.md)。
2. 启动服务后，查看电脑本机页面的 16 位配对码。
3. 手机与电脑连接同一可信 Wi-Fi，在阅读页听书面板的「电脑语音」输入配对码；自动发现失败时可填电脑局域网 IPv4。
4. 使用「测试连接」与「试听语音」确认。试听通过手机媒体声道播放，先暂停已有听书并检查媒体音量。
5. 「取消配对」右侧打开「选择朗读模型」，选择后点「保存选择」。

| 模型 | 用途 |
| --- | --- |
| 自动 | 中文、英文使用晓晓；日语优先七海，结合章节与句子语言判断 |
| 晓晓 | 固定中文／英文音色，日语读音可能不完整 |
| 七海 | 固定日语音色，适合日语及纯汉字日文；不保证中英文自然 |

试听立即使用新选择；正在听书时请停止后重新开始，让正文与预取采用新模型。纯汉字且没有假名的文本存在语言歧义，可手动选择七海。

电脑需保持登录、唤醒且可从手机访问。访客 Wi-Fi 的客户端隔离可能阻止连接。电脑离线会尝试回退手机 TTS；手机也缺语言数据时暂停提示。电脑在线后的重试不保证在被系统冻结的后台持续执行。

### 语音与隐私

- 只把当前句及预取下一句发送给配对电脑生成声音；关闭电脑语音时不使用此语音联网路径。
- 电脑语音使用带配对鉴权的局域网 HTTP，不使用 TLS 加密，请在可信网络使用，不要暴露到公网。
- 配对凭据不参与 Android 系统备份；取消配对后重新连接需要配对码。
- 部分电脑语音操作目前仍显示中文，其他应用界面和本说明支持简体中文、英文、日文。

## 全文搜索与 TXT 导出

书架搜索筛选书名／作者，书内全文搜索可定位正文。搜索结果有数量上限；取消后不会承诺所有匹配都已遍历。

导出整本或单章会生成 UTF-8 BOM、CRLF 换行的 TXT，只包含书名／作者（按操作）及章节标题和正文，不包含私人批注。可保存到下载目录并提供分享副本；下载目录写入失败时仍可能分享。它不是能恢复全部笔记、封面、分组和进度的完整备份包。

## 常见问题

- **看不到小说文件夹**：先从选文件页添加，授予系统读取权限；根目录受限时改选小说子目录。
- **移出文件夹后文件还在**：移出的是入口，文件未被删除；需要时重新添加。
- **顺序不对**：核对预计导入列表、文件顺序和分章方式；系统文件选择器不保证返回点击顺序。
- **日语无法朗读**：电脑安装七海并选择七海／自动，或检查手机日语 TTS 数据。
- **大书处理较慢**：第一次识别、全书分页与搜索需要时间；不要因 200 MiB 上限而认为所有低于上限的文件都一定可读。
- **后台听书中断**：检查通知、后台运行、电池限制和 TTS 数据；品牌系统可能冻结或回收应用，电脑也需保持唤醒。
- **导入失败／部分成功**：查看结果明细与书架，保留源文件后再尝试不同分章规则或转换格式。

## 1.14.0：全书校对、恢复与备份

单个 TXT 导入时选择「全书分章校对」，可搜索标题或章号，使用上一批／下一批检查全书；输入 `#123` 跳到归一化原文第 123 行附近，勾选遗漏标题即可补章。取消勾选会并入正文。最多保存一万处明确调整；实际导入重新核验完整文件，源文件改变后须重新校对。章节管理的「整书重新分章」也可进入同一校对页。

编号重复的候选在前后可靠编号之间比较正文距离和独立标题布局。分卷、序终章、上中下分段等受保护；证据接近时提示疑点，不强行删除，也不创造缺失正文。

导入、合并及追加按完整文件提交。进度层可暂停；书架会提示继续未完成的导入，跳过已提交文件。暂停时正在处理的那一个文件会回滚，先前文件保留。结束任务仅清除任务记录，已导入书籍保留；空的自动合并壳会移除。原文件移动、授权失效时会报告错误，可结束任务后重新选择。一次仅保留一个活动导入任务。

设置页「完整书库备份」创建 `.inkbackup` 文件，包含正文、样式、批注、阅读进度、封面、分组、分章记忆和阅读设置。备份请保存在应用之外。恢复会校验全包，在原书之外添加副本，阅读设置恢复为备份中的值；重复恢复会产生重复副本。电脑配对、文件夹授权、导入任务和性能缓存不包含在备份中。恢复预算：单项不超过 256 MiB、全包展开不超过 4 GiB、元数据不超过 16 MiB；损坏或超预算会拒绝恢复。

合并、拆章、整书重新分章成功前保存完整快照，可在章节管理菜单选择「撤销上次分章操作」。每本书保留最近一次，重启后仍有效；撤销会回到该操作前的正文、样式、批注和阅读进度，之后对该书的修改也会被这份快照替换。失败或取消不会覆盖此前的有效撤销点。

TXT 预览、合并、追加及大书重分章按磁盘索引处理。大书使用临时存储并限制行数、源大小和批注端点数量，超出预算会保留原书并拒绝操作。搜索保持精确子串及忽略大小写语义，只用索引排除确定不匹配的章节；全书页数缓存与正文、样式、排版和屏幕尺寸绑定。超大单章阅读及非 TXT 文档仍可能受到设备内存限制。

部分系统在备份名称后自动附加 `.zip`，不影响完整恢复。


## 1.14.1 审计修复

较早文件失败、后续文件成功后，继续任务会恢复原选择顺序；追加失败保留已有空书。跨越拆章点的高亮和笔记在两章各保留对应片段，首段保留原编号。空章节合并后的书签与进度不会越界。原文、样式和分章记忆读取支持恢复中断写入留下的有效备份。
