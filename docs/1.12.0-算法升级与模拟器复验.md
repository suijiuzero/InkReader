# 1.12.0 算法升级与模拟器复验

日期：2026-10-25。版本 1.12.0 / versionCode 62。Pixel_6 AVD，实际系统 API 37；构建/目标 API 34，最低 API 24。本轮仅操作模拟器，未覆盖更新手机。

## 完成的改进

- TXT 编码：BOM 和完整 UTF-8 校验优先，其余有界比较 GB18030、Big5、Windows-31J / Shift-JIS、EUC-JP；单个 TXT 可手动切换并看原文预览。判断不确定会提示，评分不是概率。
- 分章：结合标题形态、独立排版与前后编号；明确分卷后分别选择标题习惯。延续缺号局部补查、同号上下篇和特殊章保护，不生成不存在的正文。
- 目录：忽略页码引导符并按卷和编号顺序匹配，防止不同卷的第一章互相冒充；局部识别不会重新加入已确认的目录项。目录文字仍保留在正文中。
- 预览：显示补查、本卷格式、目录核对、疑似缺号及字数兜底；单个 TXT 可取消前 40 个展示的分章点，保留标题与正文。多文件详情来自第一个文件，最多检查前 5 个文件，其余章数为估算。
- 性能：统一 TXT 全文解码/切分，缓存候选行规范化，快速排除普通正文，降低重复处理；过期预览通过可中断任务与循环检查取消，预览结果不保留整本正文。
- 评估：24 份独立标注样本，81 个预期标题，另保留原 154 份多语言与边界样本。正例、短章、分卷重编号、正文引用和目录反例相互对照；预览分析与实际解析必须得到相同章节。

## 审计修复

1. 删除章节先核对章节属于传入书籍，错误组合不再删到另一书的正文；实测保留该书章节、正文、标记和统计。
2. 超长朗读句的 220 字符切分不再截断 emoji / 扩展汉字的 UTF-16 代理对，返回偏移继续对齐原文。
3. 首个章节标题后停止猜测书名，避免短正文误作元数据而被移除。
4. 卷标签不再计入弱标题的密度分母；缺少正文的同号引用不再误切。
5. 取消第一个分章点时合并前置内容，避免又生成一章前言。
6. 分卷目录以卷信息区分重复章号；修正曾多出一章的目录/局部规则组合，增加 G23、G24 对照，不从实际输出改写答案。
7. 导入预览明确失败文件与采样数量；全部失败不再显示预计一章。分章勾选行公开可读的选中状态。

同时修正两个测试问题：目录退场动画期间误收起工具栏的点击竞态；重叠资源目录造成测试包仍读取旧清单。测试资源现为单一来源，并校验清单与实际文件一一对应。早期失败/中断记录保留，不计入最终通过数。

正常 ADB 点击另外核对：日文旧编码自动识别、错误编码预览后恢复、切换编码清除旧调整、取消中间分章后实际保存两章并保留 45 段日文、阅读显示、带页码目录、本卷规则解释、疑似缺章提示、勾选状态、8 章分卷目录核对。截图与结果在忽略的本机审计目录。
