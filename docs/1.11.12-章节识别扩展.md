# 1.11.12 章节识别扩展

日期：2026-10-23；versionCode 49。

本次扩展的是章节标题写法，文件类型仍为 TXT、DOCX、Markdown、PDF、HTML、EPUB。

## 支持的新增写法

- 最终章（上/中/下）、最終章、最终话/最終話、最终回/最終回、终幕/終幕。
- 大结局/大結局、结局篇/結局篇、完结篇/完結篇、后日谈/後日談、后序、完结感言。
- 番外一、番外３、番外篇二 重逢、番外第十二章 归途。
- 自序、题记/題記、间章/間章、插章；保留原有序章、后记、幕间及英文/日文特殊章。
- 成对的中文/英文圆括号、方括号、直角引号包装；例如【最终章（上）】、【大结局】归来、Epilogue (Part One)。
- 一章 初见、01章：初见、１話（上）等省略「第」的写法；要求编号标记后有边界，不放宽成任意中文句子。
- Ch. 1、Chap. 2、Chapter No. 1、Episode #2、全角英文和 Chapter Ⅻ 等 Unicode 罗马编号。
- 【第一章 初见】、[Chapter 1 Dawn]、★ 第一章 初见 ★、正文：第一章、ＶＩＰ：第二章。
- 上卷/下卷及 Book Ⅰ/Book Ⅱ 分卷归属；① 初见等带圈数字列表沿用弱模式的正文密度检查。

字形规范化仅用于判断，不改写保存的标题或正文。目录去重也使用相同判断，兼容全角目录与半角正文编号。修正了英文 Book/Volume 混入纯章级候选、Unicode 卷名衔接时没有更新归属的问题。

## 结构化标题继续增强

- 公共章节规划结合明确章号与卷名选择层级；支持多个卷下的下一级章节、卷章同级，以及终章使用更高标题层级的排版。只有证据充分才提升子层级；多个无关上级标题或已声明的外层章仍保留原层级。
- 卷首说明、卷标题随下一章保留并更新卷归属，正文段落不丢失。Markdown 保留卷标题标记、加粗、小标题和代码原文，Setext 与 ATX 标题共用规划。
- Markdown 标题扫描跳过缩进代码与围栏代码；4 空格缩进的围栏不被当作合法关闭行。无 Markdown 标题时仍沿用原有纯文本自动识别回退。
- 用户自定义分章规则按原文字形匹配，避免全角数字、星号前缀被自动规范化后漏识别。
- 超长结构化章按固定字数切分，不再次启发式解释章内的章节引用文字；样例验证拼接各段仍得到完整原文。

分章、特殊标题排序与章首页序号提示共用识别规则。特殊章里的数字不当作正文章号，例如「番外2」属于书后内容，「第十二章 最终章（上）」仍是正文第 12 章。特殊章之间保持相同排序权重，不强制推断上中下的文件选择顺序。

边界检查保留：不把「最终章是最精彩的部分」「最终章（上）已经读完了」「番外篇里的那个人」切成新章，也不接受新增用例中的未闭合括号。清洗「最终章（上）（求月票）」只移除求票括注，保留分段标记。
