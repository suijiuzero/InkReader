## 重跑方式

```powershell
.\gradlew.bat :app:unitTest assembleDebug assembleDebugAndroidTest lintDebug
adb install --user 0 --no-streaming -r app/build/outputs/apk/debug/app-debug.apk
adb install --user 0 --no-streaming -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument --user 0 -w com.inkreader.test/com.inkreader.AuditInstrumentation
```

测试入口是独立的 `AuditInstrumentation`，不依赖额外的 Android 测试框架。测试失败会输出 `FAILED` 与异常位置，成功输出 `PASS`；Android 的命令退出码本身不能替代检查结果文本。
