# 1.15.0 日常体验与真实书源评估

日期：2026-10-29。版本 1.15.0 / 67。本轮只使用 emulator-5554 的独立测试书库；没有安装或测试实体手机，没有执行提交或推送。

## 日常体验

在旧版 1.14.2 上先运行反例：书籍写锁被占用时退出页面，最后的 731 字符位置未落盘；60 次滚动更新产生 60 次写库。原始结果为两项失败，见忽略目录 `app/build/audit/daily-before.txt`。

修复把进度写入交给应用作用域，按 120ms 短间隔合并待写快照，保留请求时的进度优先级。它是持续滚动时仍周期提交的节流，不是无限延迟到停止滚动。最终包实测 60 次更新写库 4 次，最后位置为 600；页面作用域取消后，排队的 731 位置仍成功保存。这个结果不等于测得界面帧率提升；强制结束进程或断电仍可能丢失最后尚未提交的短时间窗口。

字号与尺寸变化后按原字符锚点重定位，字体变化清理旧行布局缓存。搜索更换词回到开头，返回保留关键词和位置，避让键盘并在搜索完成／打开结果时收起键盘。操作面板或选区存在时不让音量键误触翻页。

设置新增默认关闭的「本机体验记录」。最多 200 条数值事件，记录加载、分页、布局与已绘制帧的汇总，不包含书名、正文、书籍 ID、路径、搜索词、配对信息。可手动导出 JSON 或清空，不自动上传；缓存和开关不参与书库备份，开关排除于系统备份。帧汇总仅统计收到的回调及超过 50ms 的样本，不等于系统完整卡顿率。原始性能限制没有据此宣称解决。

## 真实书源

新数据在 `tests/fixtures/real-source-v2/`：8 部公版作品、7 种语言，51 个原始章标题、301 个完整段落；原始、增加空行／缩进、无标题正文对照三种版本，共 24 例。作品级分组不会跨开发／留出分区。来源、作者、网页 SHA-256 与提取说明保留在 sources.json，50 个输入／答案／元数据文件冻结，与旧样本合计验证 187 个文件。

答案来自原书 HTML 结构，不读取分章输出；仍是本次开发整理，未经过第三方人工盲标。L 标注冻结源文本原始行号；评估器核对原始 T/L 一致，再独立按既有空行归一化契约映射。初版评估把多余空行前后的坐标直接比较造成误报，已修正评估坐标适配，冻结输入和答案未改。完整段落同时核对内容、顺序与精确重复次数。

旧版主 APK 配新评估包的实际导入基线：22 个必测案例中 16 通过、6 失败；必测章首 TP=54、FP=0、FN=36，正文错误为 0。法语、西语罗马编号和意语长标题存在漏识别。

开发分区修复后 TP=48、FP=0、FN=0。首次留出评估中英文和日文通过，意大利文两个变体各漏 6 个标题。补充连续成组、独立布局、充分正文支撑的罗马编号长标题后，最终必测案例 TP=90、FP=0、FN=0。西文章标签也支持严格罗马编号及部分首章序数词，保持原始标题不变。

Heidi 两个无编号自然语言标题变体在执行前已标为能力探测：每份仍为 TP=0、FP=0、FN=6，正文完整。它们没有被算作识别成功，也没有改答案或强行把短句当章节。最终实际导入为 22 个必测通过、2 个能力限制、0 个执行／正文失败；全部案例的预览、内存识别和磁盘导入一致。包含能力限制的整体统计为 TP=90、FP=0、FN=12，不能只引用必测子集宣称全格式准确率 100%。首次留出结果已见并用于修复，现在属于回归数据。

## 验证

- 全部新旧分区 JVM：208 项通过；主包、测试包构建成功；静态检查 0 错误、54 警告。
- 安卓：识别与可靠性 30、设备／阅读 30、顺序 17、压力 15、多格式 6、持续变更 20，共 118 项有效通过。
- 另有导航 11 项与日常逻辑 3 项通过，合计 132 项有效安卓检查。24 个来源案例包含在识别组内，不重复累加。
- 导航验证真实条目坐标、返回位置、换词回顶、关闭后重开，以及开启记录后实际收到阅读帧事件。
- 阅读验证编辑返回等待保存、实际触摸滚动、字号、横竖屏、后台恢复与空章导航。字号／旋转以字符锚点容差核对，不要求不同排版下像素相同。
- 五个后端组结果在 `app/build/audit/1.15.0-final/`；有效设备重测在 `1.15.0-device-accepted/`，导航在 `1.15.0-navigation-retry.txt`，日常逻辑在 `1.15.0-daily.txt`。原始失败日志保留。

早期界面流程被模拟器「System UI isn't responding」遮挡；随后测试辅助代码对嵌套回调的假设与后台返回命令误用 CLEAR_TASK 又导致失败。这些已修正，并重新通过全部原断言，不把失败轮次计作通过。应用主包在这些界面驱动修正期间保持不变。有效组采样最大 PSS 为 318.52 MiB，约两秒一次，不是瞬时峰值或无泄漏证明。
