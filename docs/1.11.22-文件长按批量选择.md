# 1.11.22 文件长按批量选择

日期：2026-10-24，版本 1.11.22 / 59。

仅调整墨阅内的选文件页，不影响书架首页。非“* 文件夹首页”长按文件打开批量选择菜单，普通点击仍切换单个文件。目录里的文件夹长按消耗手势但不导航，正常点击照常进入；文件夹首页长按多选移出入口保留。

菜单支持五种选择方式：

- 从此文件顺序选择：包含当前文件，选到当前列表末尾。
- 从此文件倒序选择：包含当前文件，逆序选到当前列表开头。
- 全部顺序选择：当前列表所有文件按显示顺序加入。
- 全部倒序选择：当前列表所有文件按显示顺序的逆序加入。
- 选择两个文件之间的范围：长按的文件作为起点，再在结束文件列表中点选终点，包含两端，方向从起点朝向终点；相同端点只选一个文件。可返回选择方式或取消。

所有批量操作都使用打开菜单时的当前目录、搜索和显示顺序快照，只包括支持的文件，不递归选取文件夹。已有选择及其顺序保持，新文件去重后追加到末尾；菜单展示范围文件数（含已选文件），完成时提示实际新增数量。更改显示排序不会改动已选队列。批量菜单、范围端点和队列随页面状态保存，可在后台回收后恢复。

`SelectionBatch` 负责快照和范围方向，`OrderedSelection.append` 负责跨目录队列去重追加，界面调用这两份同一实现。中、英、日三套文案覆盖新增操作。模拟器自动点击辅助工具：`tools/testing/exercise_file_batch.py`；原始截图与结果：`app/build/audit/file-batch-2026-10-24/`。
