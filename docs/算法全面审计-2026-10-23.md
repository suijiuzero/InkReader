# 墨阅算法全面复查

范围：格式/编码嗅探、ZIP 读取、纯文本章节候选与序列过滤、文件排序、结构化标题规划、PDF 段落与页眉、EPUB 阅读顺序与路径、重分章字符映射、编辑差异与样式/批注迁移。基于源码检查及可独立执行的回归测试，不代表所有真实书籍或手机场景均已覆盖。

## 本轮确认并修复

| 问题 | 后果 | 修复与证据 |
| --- | --- | --- |
| UTF-8 没有排除代理区及超过 U+10FFFF 的编码 | 非法字节被宣称为合法 UTF-8 | 增加 ED/F4 第二字节范围检查及合法上界对照测试 |
| 仅含 BOM 时没有移除 BOM | 空文件被解码为不可见正文 | UTF-8、UTF-16 大小端 BOM-only 均解码为空串 |
| PDF、OLE、ZIP 只核对部分魔数字节 | 假前缀触发错误解析器 | 核对完整签名；伪前缀与有效签名对照 |
| ZIP 后缀优先、模糊条目名识别、PPT 误报 XLSX | 改错扩展名时走错解析器 | 有界探测真实容器条目；精确匹配主文档路径，区分 PPTX/XLSX |
| ZIP 探测时 closeEntry 隐式无限解压 | 一个不相关大条目就消耗大量资源 | 探测累计 2MiB/512 条目上限；已知后缀仍可作为探测无结论时的回退 |
| Word 只限制选中的 XML，跳过媒体没有预算 | 压缩后的大媒体仍无限解压；多 XML 累计不受限 | 独立 DocxArchive 对所有条目计数、所有解压数据计量；64MiB/条目、128MiB/XML 累计、256MiB/全部解压、10000 条目；超限失败不返回半份文档 |
| 章号离群过滤没有实际距离条件，也不看卷边界 | 完整长章或明确跨卷的章节被误并入上一章 | 限于 1200 字符的短上下文，无明确卷边界才进行旧序号推断；原短引用过滤测试仍保留 |
| 小节副标题末尾数字落入通用排序回退 | “第十节 实例2”被严格章级判定为第 2 章 | 明确小节先排除；普通小节编号仍返回 10 |
| Windows 文件名处理未剥离反斜杠目录 | 目录中的 Part12 成为章节编号，标题包含目录 | 同时剥离 / 与反斜杠路径再解析 |
| 文件名字典序不能表达上中下分段 | 最终章上、下、中排列 | 对明确章节/书后标题的末尾分段构建组键及上中下序号；普通名字不强行推断；导入排序元数据与键预先读取一次 |
| PDF 数字归一化使不同章标题成为重复页眉，按全文文本删除 | 章节标题、正文中的同名文字和独立数字被删除 | 页眉判定仅作用于每页首尾两行候选；明确章/前后记标题及正文中间行保护；有句末标点的重复句子不当页眉 |

## 其他模块检查结论

- 结构化标题、Markdown 代码保护、目录全半角比较：沿用本轮前面实现，回归测试覆盖，详情见 1.11.12 章节识别说明。
- EPUB：源码按 spine 顺序读取，缺必需条目或超限拒绝；已覆盖加号、大小写路径、CRC、文本累计与总解压预算。此轮没有修改阅读顺序，不引入按文件名字典序重排。
- PDF 段落聚合：已有下一段首行保留、页面边界和英文空格回归，本轮增加页眉位置保护。
- 编辑迁移：TextEditMap 使用有界 Myers，已有 200 组随机多处修改、插入边界、删除、样式及链接同步测试；本轮未发现能确证的新差异算法错误。
- 重分章迁移：TextRemap 按全文字符来源定位，无法可靠对齐时抛错；仓库在映射完成后才写入新章节。本轮未修改其算法，不承诺任意大幅改写下都能精确保留批注。
- 写入一致性：同书写入闸门、进度版本、暂存文件与事务切换沿用既有实现及测试。

## 仍有边界，不能宣称万能识别

- 1200 字符是保守启发式阈值；短篇真实跳号和正文独立引用仍存在歧义，人工明确分章规则优先。
- PDF 只有文字与坐标，首尾两行仍只是候选位置；两栏、扫描件、特殊旋转版式和正文纯数字恰在页边的情况需要真实样书/设备验证。这里没有新增 OCR。
- ZIP 内容嗅探有预算：未知后缀且主文档在巨大附件之后时可能只识别为 ZIP；这是资源限制下的保守结果，不能宣称能识别任意改名容器。
- 无 BOM 的纯中文 UTF-16 编码推断仍有歧义，目前只对明显奇偶 NUL 分布推断大小端；本轮未冒险扩大猜测。
- 后续已用手机执行生成样本的 PDF、Word、EPUB 等实际导入；真实大型文档仍未覆盖，没有读取或修改用户书架。
- 分段排序应用于新导入文件。已有书的手动章序不自动重排，避免意外改变用户安排。
