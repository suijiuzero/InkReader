# 1.11.20 实时顺序文件选择页

日期：2026-10-24，版本 1.11.20 / 57。

## 使用方式

书架的“导入”和书籍里的“追加文件”进入墨阅自己的文件选择页。首次先用安卓系统选择小说所在的文件夹，再在墨阅内浏览和勾选；之后复用仍有效的文件夹读授权。Android 11 及以上不能授权存储根目录、下载根目录等位置，可选择它们内部存放小说的子文件夹。

文件旁实时显示已选序号。底部独立显示预计导入顺序，可展开查看、上移、下移、移除；跨子目录选择保留，同名文件按 URI 区分。浏览列表排序、搜索和目录切换不改动已选顺序；取消勾选后序号连续，再勾选时放到末尾。

确认后按队列进入原有导入或追加设置，默认“按选择顺序”，与选择页预览一致。分章方式仍可单独设置。取消选择不会导入书籍。仍保留“系统选文件”入口，用于其他位置或文件提供方。

## 状态与存储

浏览选择阶段仅查询所授权文件夹的元数据，不申请全盘管理权限。记住目录前检查实际持久读授权，授权失效时重新选择；选好文件后，导入预览及实际导入才按既有逻辑读取对应正文。

文件夹授权是系统页面，独立保存待选路由及追加目标书 ID，便于进程重建后回到正确页面。追加返回结果绑定书 ID，其他书籍不会消费这批文件。导入确认队列及其排序策略一起落盘，恢复后不回退自动排序。

## 验证

- 145 项 JVM 回归与 13 项真实 Android 隔离存储检查通过，主包/测试包构建成功，静态检查 0 错误、50 条警告、12 条提示。新增的三条警告来自用于恢复流程的同步偏好落盘，保留同步写入以免切系统页面时丢失路由。
- Pixel_6 / API 37 实际使用系统文件夹授权，再在墨阅内勾选测试文件。验证空目录、空选禁用、不支持格式过滤、跨子目录、同名文件区分、取消重选、浏览排序和搜索不改选择顺序、队列上/下移与精确移除，共记录 15 项界面检查通过。
- 横屏展开队列时，确认按钮仍完整可见并可点击；后台回收应用进程后，子目录和三个已选文件的顺序恢复成功。
- 调整后的 zeta → middle → alpha 与导入预览、最终目录及数据库一致；三份正文每份 35 个来源标记全部保留。实际从自有选择页追加两份，再经系统选择器追加一份，原书六章的索引、顺序和正文标记均正确。
- 系统选择器打开期间回收应用进程，再选择文件，仍返回原书的追加确认框，避免交给其他书消费。
- 清理唯一测试书后，勾选文件再取消选择页，未导入任何书籍，原有 396 本模拟器测试书保留；当前应用进程无致命异常。
- 本次只有模拟器连接，没有安装或操作用户手机。
