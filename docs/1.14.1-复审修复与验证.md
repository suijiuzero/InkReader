在原 1.14.0 主包上仅更新反例测试包，识别组结果为 22 通过、5 失败，原始日志位于忽略目录 `app/build/audit/algorithm-1.14.1/before-fixes/`：

1. 选择 a/b/c/d 四份无编号文件，a/c 首次写入失败，b/d 成功。继续后得到 b/d/a/c；修复后按作业凭据中的源顺序重排该作业章节，保持已有章节与批注锚点。
2. 小书重分章跨越分界的高亮只保留前半段。手工拆章也存在同类截断；两条路径均保留两侧实际片段，首段保持原 ID，笔记内容保留。
3. 将空章节并入非空前章，没有实际插入两字符分隔，却仍把书签／进度加 2，超过正文末尾；修复后偏移等于实际正文末尾。
4. 已提交样式只剩 AtomicFile 的有效 `.bak` 时返回空样式；修复统一原子读取与清理。扩查备份导出及分章记忆读取，也支持恢复有效备份。
5. 追加失败时，把已有的零章节书当成新合并任务空壳删除；修复只清理任务自动创建的空壳，并用书籍写锁保护检查与删除。

此外，结束任务与运行任务共用任务锁，防止清除正在使用的凭据；公开重排入口验证完整、本书、无重复 ID 集合，拒绝错误序列后不写库。
