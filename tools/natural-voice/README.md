# 墨阅 · 电脑语音

电脑使用已安装的 NaturalVoiceSAPIAdapter 和本地音色生成 WAV，手机负责播放。中文/英文使用 `Local-Xiaoxiao`，日语自动使用 `Local-Nanami`（七海）；没有七海时可使用已安装的其他本地日语音色。不会选择 Online/Edge/Azure 音色。`NaturalVoices.zip` 是 Windows 音色和适配器，不能直接塞进安卓安装包。

## 使用

1. Windows 安装 Python 3.10+，并确保 SAPI 中存在本地 Xiaoxiao。音色解压目录和适配器配置应保持有效，不要删除仍在使用的模型文件。
2. 双击本目录的 `启动电脑晓晓.cmd`。启动成功后打开 `http://127.0.0.1:37262/`，查看 16 位配对码。
3. 手机和电脑连接同一 Wi-Fi。墨阅阅读页 → 听书面板 → 电脑语音，输入配对码；自动查找失败时可填电脑 IPv4。
4. 使用「测试连接」「试听语音」检查。连接结果会说明是否有日语音色；“取消配对”右侧可“选择朗读模型”。试听从手机媒体声道播放，需开启手机媒体音量；听书时先暂停再试听。
5. 配对一次后自动连接。电脑不在线时回退手机 TTS；播放期间约每 30 秒尝试重连，开始听书和切章时也会查找。

`Install-Autostart.ps1` 添加当前用户登录后的启动快捷方式，`Remove-Autostart.ps1` 移除。电脑必须保持唤醒、已登录，并与手机互通；访客 Wi-Fi 的设备隔离可能阻止连接。请保留本项目及本目录的位置。

## 日语音色

晓晓属于中文音色，日语改由本地日语女声七海朗读。微软提供的日语自然音色包含 Nanami / Keita，见 [微软音色说明](https://support.microsoft.com/en-au/accessibility/windows/narrator/appendix-a-supported-languages-and-voices)。

已配置好本地晓晓的电脑，在本目录运行 `python install_japanese_voice.py`，再重新启动电脑语音服务。该工具使用 [适配器作者提供的兼容模型链接](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/wiki/Narrator-natural-voice-download-links)，下载固定版本七海模型，检查包哈希、身份、CRC 和解压边界后，放入现有 `NarratorVoicePath/Nanami`；不覆盖已有音色、不改注册表、不换配对码。已有 Nanami 目录时会停止，不覆盖。

本项目的一种本地配置目录是 `%LOCALAPPDATA%/InkReaderOffline/Voices/`；请以适配器实际登记的 `NarratorVoicePath` 为准。原始下载包可保留在下载目录，七海包缓存位于本目录忽略的 `.runtime/packages/`。模型解压目录应保持 ASCII 路径，不能移动或删除。

## 选择朗读模型

- **自动**：保留按章节/句子语言切换的行为，中文、英文使用晓晓，日语优先七海。
- **晓晓**：固定本地晓晓，适合中文和英文；不会因句中有假名而自动换七海，日语读音可能不完整。
- **七海**：固定本地 Nanami，适合日语，也能处理没有假名的日文汉字短句；不保证中文、英文读音自然，需要电脑安装对应音色。

选择页卡片下方给出对应提示。点“保存选择”才保存，取消不改变；偏好在重启和取消配对后保留。试听立即跟随新选择，自动试听参考当前正在阅读的章节语言；正在听书时停止后重新开始，正文与预取会一致使用本次选择。此设置仅用于电脑语音，离线回退仍使用手机 TTS。

含平假名/片假名的句子自动用日语；新版安卓同时根据整章假名比例提供语言上下文，让日语章节中只有汉字的短句（例如“東京。”）继续用日语。纯汉字且全文无假名的文本无法可靠区分中日文；中日混写的单句当前按一个音色朗读，不做词内切声。

电脑接口 `/v1/health` 增加 `languages`；`/v1/speak` 可选 `language: auto/zh-CN/en-US/ja-JP`。旧客户端未传语言时，电脑仍可根据假名识别普通日文；新版客户端还支持整章上下文。新版客户端遇到未声明日语能力的旧服务会回退手机；手机缺少日语数据则暂停提示，不继续用中文误读。

1.11.17 的 `/v1/health` 还返回实际可用的 `models`（`auto/xiaoxiao/nanami`），`/v1/speak` 可选 `model`。未传 model 的旧客户端继续自动选择；新版客户端不把手动模型悄悄交给不支持该参数的旧服务，需先更新电脑桥接。

## 连接与存储

- TCP 37262：HTTP 音频服务；UDP 37261：局域网发现。仅接受回环及 RFC1918 私有 IPv4。无公网映射功能。
- 本地网页显示配对码；远程请求不能读取配对码。电脑 `.runtime/config.json` 和手机专用偏好保存配对信息，均不进入代码仓库/系统备份。
- 局域网传输为 HTTP，配对用于限制访问，传输没有 TLS 加密，请在可信家庭网络使用。
- 只发送当前及预取下一句；正文不写日志。电脑合成暂存 WAV 读入后删除，手机音频播放/取消后删除。
- 暂停、跳句或切章会使旧回调失效；已经提交的电脑合成可能仍会完成，但过期结果不会播放。
- 默认关闭该功能；用户配对并启用后才有局域网通信。电脑断连时若手机也没有可用 TTS，则暂停并提示安装手机语音引擎。
- 若被系统防火墙阻止，请仅在可信专用网络上允许上述端口供本地子网访问。

## 验证

`python -m unittest discover -s tools/natural-voice -p test_bridge.py` 验证鉴权、大小限制、参数范围与音频响应。

安卓测试入口 `voiceBridge=true` 使用固定测试句，覆盖真实广播发现、配对、音频解码播放及地址恢复；`voiceService=true` 使用独立临时书库验证真实听书服务控制。不会使用用户书籍作测试。
