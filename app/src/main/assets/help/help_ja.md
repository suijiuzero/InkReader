# 墨閲 使用説明

墨閲は**完全にローカル**なリーダーです。ネット接続もアカウントも広告も不要で、手持ちの本を読み込むだけですぐ読めます。

## はじめかた

- **本の読み込み**：本棚右下のボタン → 端末内のファイルを選択 → 「1冊にまとめる」か「ファイルごとに1冊にする」を選ぶ
- **読み始める**：表紙をタップして読書画面を開く。画面中央をもう一度タップすると上下のバーが出ます

## 対応フォーマット

- **TXT**：UTF-8 / UTF-8(BOM) / GBK / GB18030 / UTF-16 を自動判別
- **DOCX**：本文と Heading 1〜6 の見出し構造を取得
- **Markdown**（`.md`）：見出し・太字・斜体・リスト・引用・コードブロック・表を保持
- **PDF**：**テキスト版のみ**（OCR 非対応）
- **HTML**：`<title>` と本文を抽出し、`h1〜h6` を章に変換
- **EPUB**：spine（読書順）に従って章ごとに抽出

## 読書の操作

- **ページ送り**：左右スワイプ、または画面の左右端をタップ。スクロールモードではそのままスクロール
- **目次**：下部バーの「目次」。上部で「章 / ノート」を切り替え
- **進捗**：下部バーの上のバーをドラッグ（章のプレビューが出て、離したときに移動）
- **注釈**：テキストを長押し → ドラッグで範囲を広げる → 4色ハイライト / しおり / ノート
- **ページまるごとタグ**：ページ送りモードで、ページを下に引くとそのページにタグを付与
- **音量キーでページ送り**：設定で有効にできます

## レイアウト設定

本棚メニューの「設定」と読書画面下部の「設定」は**同じ共通設定**です。一度変えればどこでも反映されます：

文字サイズ、行間、段落間隔、字間、余白、フォント（サンセリフ / セリフ）、テーマ、ページ送り方法、ページ送りアニメーション、先頭行の字下げ、画面の明るさ。

テーマは5種類：月白 / 紙白 / 護眼 / 深墨 / 純黒。

## 読み上げ

読書画面の「読み上げ」ボタンでシステム TTS を起動。通知バー / ロック画面から操作でき、タイマー停止とヘッドセットのボタンにも対応。段落単位での読み上げ開始もできます。

## 章の管理

書籍詳細の「章の管理」：表示・名前変更・削除・手動追加・章の自動並べ替えができます。ファイルを追加したとき、ファイル名に章番号があれば対応する位置に自動で挿入されます。

## 検索と書き出し

- **検索**：本棚上部の検索欄でタイトル / 著者を絞り込み。本の中は全文検索に対応
- **書き出し**：1冊または1章を UTF-8(BOM) + CRLF の TXT としてダウンロードフォルダに保存

## よくある質問

- **読み込んでも反応しない**：拡張子が対応一覧にあり、1ファイル 200MB 以下か確認してください
- **PDF が文字化け / 真っ白**：スキャン版（画像）PDF は文字を抽出できません。テキスト版をお使いください
- **章が分割されない**：章タイトルは単独の行にあり、「第X章 / Chapter N」のような形式である必要があります
