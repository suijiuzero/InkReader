# 墨阅使用说明

墨阅是**纯本地**阅读器：不联网、不需要账号、没有广告，导入你自己的书就能读。

## 快速上手

- **导入书籍**：书架右下角按钮 → 选择手机里的文件 → 选「合并成一本书」或「每个文件各自成为一本书」
- **开始阅读**：点封面进入阅读页；再次点屏幕中央呼出顶栏与底栏

## 支持的格式

- **TXT**：自动识别 UTF-8 / UTF-8(BOM) / GBK / GB18030 / UTF-16 编码
- **DOCX**：读取正文段落与 Heading 1–6 标题层级
- **Markdown**（`.md`）：保留排版，标题 / 粗体 / 斜体 / 列表 / 引用 / 代码块 / 表格
- **PDF**：只支持**文字版**，不做 OCR
- **HTML**：提取 `<title>` 与正文，`h1~h6` 转成章节
- **EPUB**：按 spine（阅读顺序）逐章提取

## 阅读操作

- **翻页**：左右滑动，或点击屏幕左右边缘；上下滚动模式下直接滑动
- **目录**：底栏「目录」按钮，顶部可切换「章节 / 笔记」两个页签
- **进度**：底栏上方进度条可拖动，拖动时浮出章节预览，松手才跳章
- **选中批注**：长按文字 → 拖动扩选 → 四色高亮 / 书签 / 笔记
- **整页标签**：左右翻页模式下，把整页往下拉即给这一页打标签
- **音量键翻页**：可在设置中开启

## 排版设置

书架右上角「设置」与阅读页底栏的「设置」**是同一套全局设置**，改一次到处生效：

字号、行距、段间距、字间距、页边距、字体（无衬线 / 衬线）、主题、翻页方式、翻页动画、首行缩进、屏幕亮度。

五套主题：月白 / 纸白 / 护眼 / 深墨 / 纯黑。

## 听书

阅读页「朗读」按钮启动系统 TTS 引擎，可在通知栏 / 锁屏控制，支持定时停止与耳机线控；也可「从此段开始朗读」。

## 章节管理

书籍详情页「章节管理」：可查看、重命名、删除、手动新增、自动排序章节。追加文件时，文件名里带章号会自动插到对应位置。

## 搜索与导出

- **搜索**：书架顶栏搜索框按书名 / 作者筛选；书内支持全文搜索
- **导出**：可导出整本或单章为 UTF-8(BOM) + CRLF 的 TXT，保存到下载目录

## 常见问题

- **导入了没反应**：确认文件后缀在支持列表内，且单个文件不超过 200MB
- **PDF 是乱码 / 空白**：扫描版（图片型）PDF 无法提取文字，请改用文字版
- **章节没拆开**：章节标题需独占一行，且符合「第X章 / Chapter N」这类规则
